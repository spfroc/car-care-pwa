车护助手

面向日常养车的离线优先 PWA：把加油、充电、保养与各类用车花费记在本机，随时查看油耗电耗与多车统计。

能做什么

  • 加油 / 充电记账：按车辆能源类型录入油量、电量、站点与实付金额。
  • 保养与维保：记录保养、配件、洗车、改装等养护事项，可备注下次保养里程。
  • 停车、高速、保险、罚单：把常见用车开销汇总在同一本账里。
  • 多车与能耗统计：首页花费矩阵、油耗/电耗区间与综合折算，支持 ICE / EV / PHEV / HEV 等。
  • 离线优先：数据默认保存在浏览器 IndexedDB；可导出 JSON 备份，可选云端同步（按设置）。
  • 可安装 PWA：支持添加到主屏幕，适合手机日常快速记账。

适合谁

  • 想系统记录加油保养、看清每公里花费的车主。
  • 家里有多台车，需要分别统计油耗/电耗的用户。
  • 希望数据先落在本机、减少依赖网络的人。

隐私说明

核心记账在浏览器本地完成。照片默认仅存本机；是否启用云端同步由你在设置中选择。本页仅介绍产品功能，不含账号注册墙。

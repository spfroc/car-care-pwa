车护助手

离线优先的车辆养护账本。数据在你的手机或电脑上，打开就能记一笔加油、充电或保养。

打开应用 去设置

适合谁用

  • 想随手记下油费、电费和保养，又不想先注册账号
  • 家里有燃油、纯电、插混或油电混动，需要按车分别记账
  • 经常没网或信号不好，仍要能打开账本补录

能记什么

  • 加油、充电：油量、电量、站点、实付与优惠
  • 维保、改装、洗车、配件
  • 罚单、停车费、高速费、保险
  • 可附照片（本机压缩后保存）

统计与多能源

  • 按车辆看油耗、电耗、花费和每公里成本
  • 燃油、纯电、插混、增程、油混按能源类型显示对应入口
  • 首页卡片、详情时间线和统计页共用同一套口径

数据怎么存放

  • 默认存在浏览器本地（IndexedDB），可安装到主屏幕当 PWA 使用
  • 支持导出 / 导入 JSON 备份；建议定期导出
  • 不做匿名用量上报
  • 如需跨设备，可在设置里自行接入你的 Supabase 或 Notion（自带密钥，不经过我们的账号体系）

怎么开始

  • 打开应用 → 添加第一辆车 → 在详情里记一笔，或用首页快捷入口
  • 想先看看样子：设置 → 载入演示数据
  • iOS Safari：分享 → 添加到主屏幕；Android Chrome：菜单 → 安装应用

Car Care in short

Offline-first vehicle care ledger. Log fuel, charging, service, insurance and more on this device. Install it as a PWA. No sign-up required. Optional bring-your-own Supabase or Notion sync lives in Settings.
